## 🔎 What This Document Covers

This document describes how Universum Infinitum: Planet Modifiers at https://github.com/hmlendea/stellaris-ui-planet-modifiers manages personal data. It covers the application conduct and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

This document covers the mod's local game assets and does not cover Stellaris, distribution platforms, or other software operated by third parties.

## 📥 Data We Handle

### Data Provided to the Application

- No personal data is requested by this mod. Its files provide planet modifiers, static modifiers, icon assets, and English localisation strings to Stellaris.

### Data Generated or Collected by the Application

- This mod does not generate or automatically collect personal data, telemetry, diagnostics, or usage data.

### Data Received from Integrations

- This mod does not receive personal data from integrations or third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- Provide additional planet modifiers and their generation weights — planet-modifier definition files; no personal data is involved.
- Provide modifier effects and displayed names — static modifier definitions and English localisation strings; no personal data is involved.
- Provide modifier icons — image assets consumed by the Stellaris interface; no personal data is involved.

## 🗄️ Storage, Retention, and Deletion

The mod contains no account, database, telemetry, or user-data storage component. Its definition, localisation, and image files are installed where Stellaris or the chosen mod platform stores them. This mod does not define retention or deletion of personal data. Any personal data, logs, or backups handled by Stellaris or a distribution platform are outside this mod and are controlled by the relevant provider or operator.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer or integration that receives personal data. Stellaris and any platform used to download, install, or run the mod may separately process information when users use their services; those activities are outside this mod and are governed by the respective provider's own policies.

## 🛡️ Data Protection and Security

This repository contains game definition, localisation, and image files, not a service that collects or stores personal data. The mod does not define safeguards for personal data. Review the privacy and security information provided by Stellaris and the platform used to obtain or run the mod for their respective practices.

The original maintainers are not responsible for changes, modifications, or privacy issues introduced by downstream forks.

## 🔄 Document Changes

Update this document when application data processes, storage, integrations, or deployment responsibilities change. The current version is published at [PRIVACY.md](./PRIVACY.md).

## 📬 Contact

For questions about application data handling, contact the project maintainers through [GitHub Issues](https://github.com/hmlendea/stellaris-ui-planet-modifiers/issues). For a self-hosted instance, contact the instance operator, unless the project explicitly manages the request. Include the mod version, distribution platform, and relevant data flow; do not send passwords, access tokens, or other secrets.
